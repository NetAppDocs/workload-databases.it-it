= Proteggi i carichi di lavoro di Microsoft SQL Server con Workload Factory for Databases
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Proteggi i dati delle applicazioni Microsoft SQL Server con NetApp Backup and Recovery dalla console di Workload Factory. Con questa integrazione, puoi eseguire il backup dei carichi di lavoro con snapshot locali nello storage primario Amazon FSx for NetApp ONTAP (FSx for ONTAP) e replicare i carichi di lavoro nello storage secondario FSx for ONTAP.



[[about-this-task]]
== A proposito di questa attività

Workload Factory automatizza l'individuazione delle risorse, la convalida dei prerequisiti e la configurazione e l'installazione del Plug-in for Microsoft SQL Server per prepararti a proteggere i tuoi carichi di lavoro con NetApp Backup and Recovery. Il plug-in è un componente software lato host di NetApp che ti consente di proteggere i tuoi carichi di lavoro Microsoft SQL Server.

NetApp Backup and Recovery utilizza la tecnologia di NetApp SnapMirror per la replica dei dati per garantire che tutti i backup siano completamente sincronizzati, creando copie snapshot e trasferendole nelle posizioni di backup.

Per i dettagli sulla protezione con Backup e Ripristino, fare riferimento a link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-mssql-protect-overview.html["Panoramica sulla protezione dei carichi di lavoro Microsoft SQL con Backup e Ripristino"^].



[[before-you-begin]]
== Prima di iniziare

Assicurati di soddisfare questi requisiti prima di proteggere i carichi di lavoro di Microsoft SQL Server con Backup and Recovery.

* Assicurati che il tuo ambiente soddisfi link:https://docs.netapp.com/us-en/data-services-backup-recovery/concept-start-prereq.html#microsoft-sql-server-workload-requirements["i requisiti di backup e ripristino di SQL Server"^].
* link:https://docs.netapp.com/us-en/data-services-backup-recovery/concept-start-prereq.html#in-netapp-console["Requisiti completi della console NetApp"^], tra cui la configurazione, l'assegnazione dei ruoli IAM e l'installazione di un agente Console.


Se si dispone dell'accesso come amministratore dell'organizzazione all'account NetApp , `backup and recovery super admin` il ruolo viene assegnato automaticamente quando<<Preparati alla protezione con NetApp Backup and Recovery,preparati alla protezione con NetApp Backup and Recovery>> .

* Imposta la risoluzione host sul Console agent
+
Per individuare i database, devi impostare la risoluzione host sull'agente della console. Sul dispositivo ospitato, aggiungi la mappatura dell'indirizzo IP al nome host nel file  `/etc/hosts`.

+
** link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-start-licensing.html["Impostare la licenza per NetApp Backup and Recovery"^]






[[prepare-for-protection-with-netapp-backup-and-recovery]]
== Preparati alla protezione con NetApp Backup and Recovery

Completa il processo di preparazione per proteggere le tue risorse di Microsoft SQL Server con NetApp Backup and Recovery.

.Fasi
. Accedere utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger viene utilizzata per navigare tra carichi di lavoro quali storage, eda, ai, database, vmware e amministrazione."] e quindi selezionare *Database*.
. Dal menu Database, selezionare *Inventario*.
. Nell'inventario, seleziona *Microsoft SQL Server* come tipo di motore.
. Individua l'istanza che desideri proteggere, quindi seleziona *Proteggi* dal menu.
. Se richiesto, fornire le credenziali di Windows con accesso amministrativo.
+
Per utilizzare NetApp Backup and Recovery per la protezione, le istanze di SQL Server devono essere registrate in Workload Factory con le credenziali di Windows.

. Se sono attivi e disponibili più agenti della console, selezionare l'*agente della console* in cui si desidera registrare e proteggere il carico di lavoro.
. Seleziona *Avvia* per prepararti alla protezione dei dati. Workload Factory registra automaticamente le risorse di SQL Server in Backup and Recovery, configura e installa il plug-in per Microsoft SQL Server e rileva le risorse necessarie per soddisfare i prerequisiti per proteggere l'istanza di SQL Server.
. Una volta soddisfatti i prerequisiti, seleziona *Redirect* per accedere a Backup and Recovery.


.Cosa succederà
Da Backup e ripristino, crea un criterio per proteggere l'istanza e i database di Microsoft SQL Server.

link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-policies-create.html["Scopri come creare un criterio per proteggere l'istanza e i database di Microsoft SQL Server"^].

Per informazioni correlate, fare riferimento a link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-mssql-protect-overview.html["Documentazione di backup e ripristino"^] per la gestione dei carichi di lavoro di Microsoft SQL Server.



[[edit-protection-for-microsoft-sql-server-resources]]
== Protezione dalle modifiche per le risorse di Microsoft SQL Server

È possibile modificare la protezione per le istanze e i database di Microsoft SQL Server già protetti in NetApp Backup and Recovery. La modifica della protezione consente di modificare i criteri di protezione o la pianificazione per le istanze di SQL Server protette.

. Accedere utilizzando uno dei link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["esperienze di console"^].
. Seleziona il menu image:workloads-menu-icon.png["L'icona del menu hamburger viene utilizzata per navigare tra carichi di lavoro quali storage, eda, ai, database, vmware e amministrazione."] e quindi selezionare *Database*.
. Dal menu Database, selezionare *Inventario*.
. Nell'inventario, seleziona *Microsoft SQL Server* come tipo di motore.
. Selezionare la scheda *Database*.
. Individua il database per cui modificare la protezione, quindi seleziona *Modifica protezione* dal menu.
+
Verrai reindirizzato a Backup e ripristino nella NetApp Console , dove potrai modificare la policy o la pianificazione della protezione.
